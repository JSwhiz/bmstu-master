# Магистратура МГТУ им. Н. Э. Баумана

Личный репозиторий для учебных материалов, лабораторных и отчётов в магистратуре МГТУ им. Н. Э. Баумана.

## Содержимое

| Раздел | Назначение |
| --- | --- |
| [`report/`](report/) | Шаблон отчёта в формате Typst с оформлением по ГОСТ. |
| [`mlcourse`](https://github.com/JSwhiz/mlcourse) | Практика по курсу mlcourse.ai; ведётся в отдельном репозитории. |

## Отчёты

Шаблон находится в [`report/0.0.9`](report/0.0.9). Он написан на [Typst](https://typst.app/) и содержит титульный лист, параметры оформления и стиль библиографии ГОСТ.

Для начала работы создайте отдельную папку для дисциплины или работы, скопируйте нужные файлы шаблона и укажите свои данные в вызове `template`.

Для сборки нужен Typst версии 0.14 или новее:

```bash
typst compile report.typ report.pdf
```

## Организация материалов

Учебные материалы лучше хранить по дисциплинам:

```text
<дисциплина>/
├── labs/          # лабораторные работы
├── assignments/   # домашние и практические задания
├── notes/         # конспекты и заметки
└── reports/       # исходники отчётов
```

Не добавляйте в репозиторий персональные данные, выданные преподавателем закрытые материалы и объёмные исходные наборы данных.

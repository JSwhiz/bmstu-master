## 📌 О репозитории

`bmstu-master` — личное рабочее пространство для материалов магистратуры МГТУ им. Н. Э. Баумана.

Репозиторий задуман не как набор разрозненных файлов, а как единая структура для ведения обучения:

- лабораторных и практических работ;
- домашних заданий;
- конспектов и заметок;
- исходного кода;
- академических отчётов;
- материалов по отдельным учебным курсам.

Сейчас основная готовая часть репозитория — универсальный **Typst-шаблон отчёта**, который можно использовать как основу для лабораторных, практических, домашних и контрольных работ.

## 📝 Шаблон отчёта

Актуальная версия находится в [`report/0.0.9`](report/0.0.9).

Шаблон построен на **Typst 0.14+** и предназначен для повторного использования в учебных работах.

### Возможности

- титульный лист с параметрами студента, преподавателя, кафедры и дисциплины;
- формат страницы A4 и единые параметры оформления;
- русская типографика и корректные кавычки;
- оформление формул и перекрёстных ссылок;
- рисунки и таблицы с автоматической нумерацией;
- корректные подписи и ссылки на рисунки и таблицы;
- листинги исходного кода с нумерацией строк;
- поддержка библиографии;
- стиль списка источников **ГОСТ Р 7.0.5–2008**;
- возможность использовать `.bib` и Hayagriva `.yaml/.yml`;
- подготовленная инфраструктура для создания однотипных отчётов без копирования оформления вручную.

## 🚀 Быстрый старт

### 1. Установить Typst

Проверьте установленную версию:

```bash
typst --version
```

Для текущего шаблона требуется **Typst 0.14.0 или новее**.

### 2. Подготовить работу

Создайте папку нужной дисциплины или лабораторной и используйте шаблон из `report/0.0.9`.

Пример подключения:

```typst
#import "../../report/0.0.9/report.typ": *

#show: template.with(
  group: "Группа",
  student-name: "И. И. Иванов",
  professor-name: "А. А. Андреев",
  course-name: "Название дисциплины",
  report-type: "лабораторная",
  report-number: 1,
  title: "Название работы",
  faculty: "Название факультета",
  department: "Название кафедры",
  city: "Москва",
)

= Цель работы

Текст отчёта.
```

### 3. Собрать PDF

```bash
typst compile main.typ report.pdf
```

Для автоматической пересборки во время редактирования:

```bash
typst watch main.typ report.pdf
```

## 📚 Рекомендуемая организация дисциплин

Для учебных материалов предполагается единообразная структура:

```text
<discipline>/
├── README.md         # описание дисциплины и навигация
├── labs/             # лабораторные работы
├── assignments/      # домашние и практические задания
├── notes/            # конспекты и заметки
├── reports/          # исходники отчётов
└── assets/           # изображения, схемы и вспомогательные файлы
```

Такой подход позволяет хранить исходники, отчёты и заметки рядом, но не превращать корень репозитория в набор несвязанных файлов.

## 🧭 Принципы ведения репозитория

Материалы стараются храниться в воспроизводимом виде: исходный код вместо одних только скриншотов, `.typ` рядом с отчётом, понятная структура директорий и отдельная папка под каждую дисциплину.

В Git не следует добавлять:

- персональные или конфиденциальные данные;
- закрытые материалы преподавателей;
- пароли, токены и `.env` с секретами;
- временные файлы сборки;
- большие датасеты и бинарные файлы, если они могут храниться отдельно.

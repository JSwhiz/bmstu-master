# Магистратура МГТУ им. Н. Э. Баумана

Это мой рабочий репозиторий по магистратуре. Здесь я хочу хранить не просто файлы «для сдачи», а нормальную базу знаний по предметам: лекции, собственные пояснения, практические работы, код и отчёты.

Главный принцип простой: если я открою этот репозиторий через полгода, я должен быстро понять, **что мы проходили, зачем это было нужно и где лежит нужный материал**.

## Как устроен репозиторий

```text
bmstu-master/
├── Управление персоналом/
│   ├── README.md
│   └── Лекции/
│       └── Лекция 01 — Организация управления персоналом.md
│
├── report/
│   └── 0.0.9/       # мой общий Typst-шаблон для учебных отчётов
│
└── README.md
```

Новые дисциплины буду добавлять отдельными папками. Внутри каждой — свой README, который работает как содержание предмета и показывает, что уже пройдено.

## Как я хочу вести предметы

В лекциях мне недостаточно просто переписать текст со слайдов. Поэтому конспекты делаю в двух слоях:

1. **Исходный материал преподавателя** — сохраняю формулировки максимально дословно.
2. **Мой разбор** — раскрываю смысл, связываю определения между собой, добавляю примеры и то, что стоит запомнить.

Так исходный материал не теряется, но из набора слайдов постепенно получается конспект, по которому действительно можно учиться.

## Отчёты

Для лабораторных, практических и других письменных работ здесь лежит общий шаблон на Typst:

[`report/0.0.9`](report/0.0.9/)

В нём уже настроены титульный лист, форматирование, рисунки, таблицы, формулы, листинги кода и библиография по ГОСТ. Вместо того чтобы каждый раз заново оформлять документ, хочу подключать один и тот же шаблон из работы.

Минимальная команда сборки:

```bash
typst compile main.typ report.pdf
```

А при редактировании удобнее:

```bash
typst watch main.typ report.pdf
```

## Что хочу получить в итоге

Не архив файлов ради архива, а личную учебную базу:

- лекции, которые можно перечитать перед экзаменом и действительно понять;
- короткую навигацию по каждому предмету;
- практические и лабораторные работы рядом с теорией;
- исходники вместо одних PDF;
- единое оформление отчётов;
- заметки о сложных или особенно важных местах.

Репозиторий будет меняться вместе с учебой: структура здесь не «финальная», а рабочая.

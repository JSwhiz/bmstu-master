## Отчёты

[`report/0.0.9`](report/0.0.9/) — общий шаблон на Typst для учебных работ.

Уже есть титульный лист, таблицы, рисунки, формулы, листинги и библиография по ГОСТ.

```bash
typst compile main.typ report.pdf
```

Во время работы:

```bash
typst watch main.typ report.pdf
```

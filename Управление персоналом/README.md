# Управление персоналом

Учебные материалы по дисциплине **«Управление персоналом»** в магистратуре МГТУ им. Н. Э. Баумана.

Этот раздел используется как единая точка хранения лекций, конспектов и последующих учебных материалов по предмету. Тексты лекций переносятся из материалов преподавателя без содержательного редактирования, чтобы сохранить исходные формулировки.

## Структура

```text
Управление персоналом/
├── README.md
└── Лекции/
    └── Лекция 01 — Организация управления персоналом.md
```

## Принцип ведения

- Материал лекций сохраняется в Markdown (`.md`).
- Формулировки со слайдов переносятся максимально дословно.
- Порядок материала соответствует порядку слайдов преподавателя.
- Каждый слайд выделяется отдельно, чтобы лекцию можно было последовательно дополнять новыми материалами.
- Дополнительные пояснения и собственные заметки, если они появятся, следует отделять от исходного текста преподавателя.

## Назначение раздела

Цель — постепенно сформировать структурированный архив дисциплины, пригодный одновременно для подготовки к занятиям, повторения материала и дальнейшей подготовки к зачёту или экзамену.

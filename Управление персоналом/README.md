## Коротко по первой лекции

- человек — особый ресурс: у него есть свои цели, эмоции и мотивация;
- одинаковое управленческое решение может по-разному повлиять на разных людей;
- интересы работника и организации не совпадают автоматически;
- работодатель получает не только труд сотрудника, но и его знания, интеллект и инициативу;
- зарплата — только одна часть мотивации;
- потребности работника удобно разбирать по уровням Маслоу;
- **управление персоналом** больше связано с системой отношений и работой с сотрудниками;
- **управление человеческими ресурсами** рассматривает людей как стратегический ресурс организации.

### Запомнить

> Хороший специалист сам по себе ещё не гарантирует хороший результат. Нужны способности, нормальные условия и мотивация.

> Деньги закрывают далеко не все потребности сотрудника. После определённого уровня на первый план могут выйти стабильность, коллектив, признание, рост и интерес к самой работе.
